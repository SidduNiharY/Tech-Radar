# TechRadar Vault Guidelines

- `wiki/news/`: Generated story notes. Do not hand-edit; regenerated on source update.
- `syllabus/`: Exam syllabus tracking and notes.
- `foundations/`: Foundational topic knowledge bases.
- `skills/`: Tool and technical skill guides.
- `context/`: Personal goals, interests, and profile files.
- `projects/`: User project plans and writeups.
- `references/`: Reference materials and primary docs.
